# 2026-10-20 — 2.0.0 (Specnico)

Mudança incompatível: o pacote `@robertourias/scaffold-ia` 1.x passa a se chamar
`specnico` e ganha novo fluxo e layout, inspirados no Spec Kit.

## O que mudou

- feat: pacote `specnico` 2.0.0 (binário `specnico`); versão instalada em `.specify/.specnico-version`
- feat: 10 comandos como skills `specnico-*`: constitution, spec, clarify, plan, analyze, approve, implement, converge, review, fix
- feat: Specs em pasta `specs/NNN-slug/{spec,plan,tasks}.md`; bugs em `specs/bugs/`
- feat: estado ativo em `.specify/state.json`, lido por todo comando e pelo `spec-gate`
- feat: `product-backlog.md` em fases, com IDs `Bnn` e índice de features
- feat: `npx specnico --migrate` converte projetos 1.x (idempotente, retomável)
- refactor: `docs/` deixa de existir; memória em `.specify/memory/`, processo em `.specify/{templates,packs,workflows}`
- refactor: `spec-gate` lê `state.json` e cobre `spec.md` e `plan.md` (emenda em Spec aprovada)
- refactor: `SPECNICO_VERIFY=0` desliga os hooks (`SCAFFOLD_VERIFY=0` segue como alias)
- docs: README e `.claude/README.md` reescritos; `lint-docs` valida `/specnico-*` citados e rejeita comandos removidos fora do guia de migração

## Removidos → substitutos

| Removido | Substituto |
|---|---|
| `init-project`, `backlog`, `groom` | `/specnico-constitution` |
| `spec` | `/specnico-spec` (o quê) e `/specnico-plan` (como) |
| `approve` | `/specnico-approve` |
| `hands-on`, `back`, `front` | `/specnico-implement [Tnnn,…]` |
| `recheck` | `/specnico-converge` |
| `review` | `/specnico-review` |
| `init-app`, `init-package` | item de arquitetura no backlog |
| `pr-open` | passo final do `/specnico-implement` |
| `pr-merged` | manual (`git switch`, `git pull`, `git branch -d`) |
| `checkpoint`, `retomar` | `state.json` + `tasks.md` + `git log` |

## Migração

`npx specnico@latest --migrate` (ver o README). Recusa com Spec 1.x aprovada e
inacabada. Dados vão para `.specify/memory/` e `specs/legacy/`; o harness 1.x é
removido. Revise `git status` e adicione `.claude .specify specs` explicitamente.

## Pendente (mantenedor)

`npm publish` e `npm deprecate @robertourias/scaffold-ia "Renomeado para specnico — npx specnico@latest --migrate"`.
