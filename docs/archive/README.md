# Archive

Specs **concluídas**. Movidas para cá por `/checkpoint` (Passo 4) ou pela Fase 6 do
`docs/workflows/feature-delivery.md`.

## Por que esta pasta existe

Spec concluída continua sendo histórico útil (o "porquê" de uma decisão), mas não deve
mais ser carregada por `/spec`, `/retomar` ou `/hands-on`. Arquivar mantém
`docs/specs/` pequeno — que é onde os agentes procuram trabalho ativo.

## Regra de arquivamento

Uma Spec só sai de `docs/specs/` quando:

1. `Status: approved`, **e**
2. **Todos** os Critérios de Aceite de **todas** as tarefas estão `[x]`.

Se houver qualquer `[ ]`, a Spec permanece em `docs/specs/`.

## Regra de leitura

Agentes **não** leem esta pasta por padrão. Leia um arquivo daqui apenas quando
investigar explicitamente o histórico de uma decisão passada.
